# LoveUniverse

Интерактивная 3D-открытка на JavaScript и WebGL. Галактика из частиц, объёмное сердце и вращающиеся иконки объединяют фотографии, подарки и любимую музыку в небольшую личную историю.

Проект посвящён анимации и взаимодействию в браузере: процедурной генерации частиц, согласованному движению объектов в 3D-сцене и адаптации интерфейса для компьютеров и телефонов.

## Возможности

- Экран-приглашение и вход с паролем как элемент сюрприза.
- Плавное появление галактики, процедурное сердце и орбиты романтических фраз.
- Автоматическое вращение и управление сценой мышью или касанием с инерцией.
- Четыре карточки: совместный кадр, фотоальбом, любимые треки и подарки.
- Отдельные слои сцены: сердце отображается поверх орбитальных иконок.
- Адаптивные диалоги с плавным открытием и закрытием по крестику или нажатию вне окна.

## Техническая реализация

**Стек:** JavaScript, HTML, CSS, WebGL 1, GLSL, Canvas 2D, Web Animations API, GitHub Pages. Без фреймворков, npm-зависимостей и этапа сборки.

| Код | Назначение |
| --- | --- |
| [app.js](app.js) | Цикл анимации, ввод, инерция, переходы и открытие карточек |
| [scene-math.js](scene-math.js) | Проекция, раскладка, этапы появления и орбиты |
| [galaxy-renderer.js](galaxy-renderer.js) | Геометрия частиц и WebGL-шейдеры галактики и сердца |
| [glyph-renderer.js](glyph-renderer.js) | Мобильный рендер подписей: атлас букв и пакетная отрисовка |
| [memory-media.js](memory-media.js) | Фотографии карточек и последовательная предзагрузка |
| [content.js](content.js) | Тексты, настройка входа, иконки и наборы медиа |
| [style.css](style.css), [index.html](index.html) | Оформление, адаптивная разметка и диалоги |

Положение частиц вычисляется в шейдерах. Галерея и содержимое карточек заданы данными и не зависят от отрисовки сцены. Для мобильных устройств используется отдельный бюджет частиц, а подписи собираются в общий атлас и передаются в WebGL одним пакетом. При скрытии вкладки цикл анимации приостанавливается; фотографии предзагружаются после появления сцены.

Для знакомства с проектом начните с `scene-math.js` и `app.js`: они показывают связь проекции, ввода и анимации. `glyph-renderer.js` демонстрирует пакетную отрисовку текста без отдельного Canvas-вызова для каждой буквы.

## Запуск

Откройте [онлайн-версию](https://qwertynoqwerty.github.io/love-universe/) или запустите локальный статический сервер в корне репозитория:

```bash
python -m http.server 8000
```

Перейдите на `http://localhost:8000`. Для 3D-сцены браузер должен поддерживать WebGL. Папка `assets` должна находиться рядом с `index.html`.

## Управление

Нажмите «Заглянуть внутрь», пройдите экран входа и дождитесь появления сцены. Перетаскивание мышью или пальцем меняет угол вращения. Нажатие на иконку открывает соответствующую карточку. Чтобы закрыть её, нажмите крестик или область вокруг окна.

## Настройка и публикация

Тексты и карточки редактируются в `content.js`: `phrases` задаёт орбитальные подписи, `memories` - содержимое карточек, `art` - орбитальную иконку, `media` - фотографии. Вход реализован на клиенте как часть открытки и не предназначен для защиты доступа к файлам.

Сайт публикуется из ветки `main` через GitHub Pages. Файл `.nojekyll` отключает обработку Jekyll, а относительные пути позволяют разместить проект по адресу репозитория.
